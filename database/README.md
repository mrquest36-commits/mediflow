# MediFlow Database Architecture

## Purpose

This folder contains database design documents and migration scripts for MediFlow.

The database is designed as a multi-hospital healthcare management platform.

## Core Principles

- Multi-hospital support
- Patient data isolation
- Scalable relationships
- Audit-friendly structure
- Future module compatibility

## Main Entities

- Hospitals
- Users
- Patients
- Appointments
- Medical Records
- Prescriptions
- Laboratory
- Billing

## Migration Order

1. Hospitals
2. Patients
3. Patient Identification
4. Emergency Contacts
5. Medical Profiles
